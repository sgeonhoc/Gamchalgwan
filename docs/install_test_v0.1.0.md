## 체크리스트 — 만든 PC

- **첫 실행 창** — 이 PC 에서는 아무 창도 안 떴다. 직접 만든 zip 이라 인터넷에서 받은 표시가 없어 SmartScreen 이 안 뜨고, VC++ 런타임도 이미 깔려 있다. 링크로 받는 다른 PC 에서 봐야 한다.
- **첫 화면까지** — 실행부터 첫 녹화 프레임까지 14.7초(첫 실행 · 셰이더 준비 포함), 다시 켤 때 2.1초.
- **루프 한 바퀴** — Shipping 실행 파일로 두 판이 끝까지 돌았다. 1902 장을 남겼고, 그중 열어 본 시작 · 기록 요청 · 기록 · 조합 · 붙잡힘 · 결말 장에 한글 글이 다 찍혀 있었다.
- **창 모드 · 해상도** — 옵션 없이 켜니 창 모드 1280×720 으로 떴다(클라이언트 영역 1280×720). 한글 글(시각 · 목표 · 꼬리표 · 패널 · 조작 안내)이 다 보였고, 실제 마우스로 관리인을 누르자 관리인 꼬리표가 노랗게 바뀌고 아래 패널(설명 · 「다가가기 +5분」)이 열렸다.
- **끄기** — 자동 플레이 두 판 뒤 엔진 정상 종료로 꺼졌다(종료 코드 0 · 남은 프로세스 0 · 크래시 폴더 없음). 창 모드에서는 창 닫기로 꺼 봤고 정상 종료 · 남은 프로세스 0 이었다. Esc · 「끝내기」 버튼으로 끄는 것은 아직 손으로 눌러 보지 않았다.
- **링크로 받은 설치본** — GitHub 릴리스 링크 셋(zip · 12초 클립 · 63초 클립)이 다 열렸고 크기가 올린 파일과 같았다. zip 은 받아서(48초) SHA-256 을 대 봤고, 위에서 테스트한 zip 과 같았다(`7DF2A15C…7311E6E7`). 그래서 링크로 받은 설치본은 위 두 줄의 결과를 그대로 갖는다.
- **다시 켜기** — 두 번째 실행도 2.1초 만에 첫 화면이 떴고, 90 장을 찍고 종료 코드 0 으로 꺼졌다. 저장할 진행이 없는 한 판 게임이다.

## 테스터에게 보낸(보낼) 안내 한 줄

압축을 풀고 Windows\Gamchalgwan.exe 를 누르세요. 파란 「Windows의 PC 보호」 창이 뜨면 「추가 정보」 → 「실행」. 마우스 클릭만으로 됩니다(R 다시 · Esc 끝내기).
